# Phase5 スモークテスト手順

## 事前準備
- `npm run build`
- `npm run dev`
- ブラウザで `#/history` を開く

## Local モード確認
1. **体重入力 -> グラフ反映**
   - `体重・体脂肪` タブで日付/体重/体脂肪を入力して保存
   - 7日/30日タブで折れ線が更新されることを確認
2. **ワークアウト -> カレンダー印 -> 日付詳細**
   - クエストを1本完了して履歴を作る
   - `カレンダー` タブで当日に印が付くことを確認
   - 日付をタップし、当日の一覧（exercise/quest, kcal, pt）が表示されることを確認
3. **前日/翌日遷移**
   - 日付詳細の `前日` / `翌日` ボタンで日付が切り替わり、一覧が追随することを確認

## Supabase モード確認
1. **ログインして同様に動作**
   - Google ログイン後、上記 Local と同じ操作を実行
2. **復元確認（別ブラウザ/別端末）**
   - 同一アカウントでログイン
   - 体重/体脂肪ログが復元されることを確認
3. **カレンダー/日付詳細の一致**
   - 同じ月・同じ日付で、トレーニング印と当日一覧が一致することを確認

## 回帰確認（Phase4）
- `#/timeline` で読み込み・scope 切替・like が動作する
- follow/unfollow と visibility 更新が従来通り動作する
